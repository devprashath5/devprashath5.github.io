# devprashath5.github.io

Static public website for **VEXA Technologies** (a private project; not a registered company):
the home page and privacy policy used for the Google OAuth app branding.

- `index.html`: home page
- `privacy.html`: privacy policy (Google API Services User Data Policy / Limited Use)
- `styles.css`, `favicon.svg`, `404.html`

Plain HTML and CSS: no JavaScript, external fonts, analytics, tracking or cookies.
It contains nothing about the private infrastructure (no internal hostnames, IPs, keys or lead data).

Published with GitHub Pages from the `main` branch root. Free.

If the project's data handling changes (new scopes, new providers, different retention), update `privacy.html`
and its effective date **before** the change goes live.
